# Day 01 검사 문제 정의 — ROI 비교 기록

> 아래 관찰은 `outputs/roi/*_preview.jpg`와 `outputs/video_roi/*_preview.jpg`를 눈으로 확인한 결과입니다. 좌표 값은 눈대중이라 대략적인 수치입니다.

## 1. 사용한 ROI 좌표 (고정)

```text
x1 = 170, y1 = 120, x2 = 470, y2 = 500   → ROI 크기 300 × 380
```

## 2. ROI 설정 과정 (1차 시도 → 개선 → 최종)

| 단계 | 좌표 (x1, y1, x2, y2) | 내용 |
|---|---|---|
| 첫 시도 (교재 예시) | (200, 100, 700, 500) | 이미지 너비(640)를 넘어 `x2`가 640으로 보정되고, 병뚜껑(x 190~450) 오른쪽 배경이 많이 포함됨 |
| 그리드 보고 수정 | (170, 120, 470, 450) | 병뚜껑 폭에 맞춤. `sample01`에는 잘 맞지만 병뚜껑이 더 아래에 있는 이미지에서는 아래쪽이 잘릴 수 있음 |
| 최종 선택 | (170, 120, 470, 500) | 아래쪽에 약 50px 여유를 줌. 위치가 조금 달라진 정상 이미지도 포함하도록 함 |

## 3. 이미지 5장에 같은 ROI를 적용한 결과

| 이미지 | 실제 상태 | ROI 결과 | 관찰 |
|---|---|---|---|
| `sample01` | 뚜껑 있음 | 성공 | 기준 이미지. 뚜껑 전체(y 약 140~445)가 ROI 안에 들어오고, 아래쪽에 병목 일부가 포함됨 |
| `sample02` | 뚜껑 있음 | 성공 (여유 적음) | 뚜껑이 기준보다 아래에 있음(y 약 195~495). 뚜껑 아래쪽이 ROI 아래 경계(y 500) 가까이에 닿아 여유가 거의 없음 |
| `sample03` | 뚜껑 있음 | 성공 | 뚜껑이 y 약 185~460, x 약 205~440으로 ROI 안에 완전히 들어옴 |
| `sample04` | 뚜껑 없음 | ROI 정상 | 검사 위치는 맞지만 뚜껑이 없고 투명한 병 입구(나사산)만 보임. 불량 후보 |
| `sample05` | 뚜껑 없음 | ROI 정상 | 병 입구가 더 높은 위치(y 약 185부터)에 있지만 ROI 안에 있음. 뚜껑이 없는 불량 후보 |

- `sample04`, `sample05`는 ROI 실패가 아닙니다. ROI 위치는 맞고, 그 안에 있어야 할 병뚜껑이 없는 경우입니다.
- 5장 모두 해상도가 640 × 640으로 같습니다.
- `sample02`처럼 뚜껑 위치가 조금만 더 아래로 내려가면 ROI 아래쪽에서 잘릴 수 있습니다. 이 ROI가 안전한 위치 변화 범위는 아래쪽 약 5px 정도로 매우 좁습니다.

## 4. 영상(`sample.mp4`)에 같은 ROI를 적용한 결과

| 항목 | 값 |
|---|---|
| 영상 크기 / FPS | 1280 × 720 / 24 |
| 전체 Frame | 240 |
| 저장 Frame (30 Frame마다) | 8 |

| Frame | 관찰 |
|---|---|
| 30 | 병이 오른쪽(x 약 610 이후)에 있고 ROI에는 빈 배경만 들어옴 |
| 90 | 빨간 병뚜껑이 x 약 540~720, y 약 125~175에 있는데 ROI(x 170~470)는 그 왼쪽의 빈 배경임 |
| 240 | 병 입구(뚜껑 없음)가 x 약 540~710에 있고 ROI에는 빈 배경만 들어옴 |

- 이 ROI 좌표는 640 × 640 사진 5장에 맞춘 값이라, 1280 × 720 영상에서는 검사 대상을 전혀 포함하지 못했습니다.
- 영상에서는 병을 손으로 들고 있어 병의 위치가 Frame마다 크게 달라집니다.
- 이것은 제품 문제가 아니라 **검사 환경 문제**(해상도와 촬영 조건이 사진과 다름)입니다.

## 5. 이번 기록에서 확인한 것

```text
한 장에서 잘 맞는 ROI ≠ 모든 이미지에서 잘 맞는 ROI
사진에서 정한 ROI ≠ 영상에서도 맞는 ROI
```

- ROI가 제품을 놓친 경우는 검사 영역의 문제이고, ROI 안에 뚜껑이 없는 경우는 실제 불량 후보입니다.
- 고정 ROI는 카메라 위치, 해상도, 제품 위치가 일정할 때만 안정적입니다.
