# Day 03 Mini Challenge 결과

> 코드: `src/23_day03_challenge.py` · 결과 이미지: `outputs/day03/challenge/` · 측정값: `reports/day03_challenge_results.csv`

## 1. 검사 문제

검사 유형: 교재 23.1의 **C. 색상 객체 검사**

검사 대상: 콜라병 입구의 빨간 병뚜껑

정상 상태: 병 입구에 빨간 병뚜껑이 닫혀 있음

불량 상태: 병뚜껑을 딴 상태(입구에 빨간 뚜껑이 없음)

눈으로 보이는 차이: 병 입구에 선명한 빨간색 영역이 있는가 / 없는가

이미지 준비: 직접 촬영하는 대신 1일차 `samples/sample.mp4`(1280×720, 손으로 든 병)에서 Frame을 저장해 사용했다.

| 파일 | 원본 Frame | 실제 상태 | 역할 |
|---|---|---|---|
| `ok_01.jpg` | #75 | 뚜껑 있음 | Rule 결정 |
| `ng_01.jpg` | #210 | 뚜껑 없음 | Rule 결정 |
| `ok_02.jpg` | #105 | 뚜껑 있음 | 확인 |
| `ng_02.jpg` | #225 | 뚜껑 없음 | 확인 |
| `ok_03.jpg` | #150 | 뚜껑 있음(병따개가 일부 가림) | 확인 |
| `ng_03.jpg` | #195 | 뚜껑 없음 | 확인 |

## 2. 사용한 처리

처리 흐름:

```text
BGR
→ HSV
→ 빨강 Color Mask (H 0~4 또는 170~180, S ≥ 90, V ≥ 120)
→ Morphology (5×5 타원 Kernel, Opening → Closing)
→ Contour
→ Feature
→ Rule
```

- **Gray / Otsu를 쓰지 않은 이유:** 정상과 불량의 차이가 밝기나 형태가 아니라 **색**이다. 또 병을 손으로 들고 있어 위치가 계속 바뀌므로, 1일차처럼 고정 ROI를 쓰지 않고 전체 Frame에서 색으로 찾았다.
- **마스크 범위를 정한 과정(먼저 측정):** 처음에 넓은 빨강 범위(H 0~10, S ≥ 80, V ≥ 60)를 쓰니 **손(피부)과 콜라 표면**도 빨강으로 잡혀, `ok_03`에서는 손이 가장 큰 객체(23%)가 되었다. 그래서 객체별 H·S·V를 측정했다.

| 객체 | H | S | V |
|---|---:|---:|---:|
| 빨간 뚜껑 | 0~3 | 약 135 | 약 175 |
| 손(피부) | 7~8 | 약 105~115 | 약 190~205 |
| 콜라 | 4 | 약 222 | 약 80 |

  → H 상한을 4로 좁혀 피부를 빼고, V ≥ 120으로 어두운 콜라를 뺐다. (H 상한 5는 `ok_03`에서 피부 조각이 7개로 늘어 4를 선택했다.)
- **Morphology가 필요한 이유:** 마스크에 손 가장자리의 작은 빨간 점이 남아서 Opening으로 지우고, 뚜껑 글씨 사이의 작은 틈은 Closing으로 메웠다.

## 3. 선택한 Feature

Feature: `largest_red_area_ratio` (가장 큰 빨간 객체 면적 / 전체 이미지 면적)

선택 이유: 뚜껑이 있으면 병 입구에 뚜렷한 빨간 덩어리가 하나 생기고, 없으면 거의 0이 된다. `valid_count`는 손 조각 때문에 정상끼리도 1~4로 흔들려서 Rule에는 쓰지 않고 참고값으로만 기록했다. `center`(세로 약 0.20)는 가장 큰 객체가 실제로 병 입구에 있는지 확인하는 용도로 봤다.

## 4. 실제 측정값

| 파일 | largest_red_area_ratio | valid_count | center (x, y) |
|---|---:|---:|---|
| ok_01 (정상) | 0.004948 | 1 | (0.473, 0.200) |
| ng_01 (불량) | 0.000000 | 0 | - |
| ok_02 (정상) | 0.005202 | 2 | (0.493, 0.207) |
| ng_02 (불량) | 0.000000 | 0 | - |
| ok_03 (정상, 가림) | 0.006927 | 4 | (0.469, 0.199) |
| ng_03 (불량) | 0.000000 | 0 | - |

## 5. Rule

기준 한 쌍(ok_01 / ng_01)의 중간값을 Candidate Threshold로 정하고 **Test 전에 고정**했다.

```text
candidate_threshold = (0.004948 + 0.000000) / 2 = 0.00247
```

OK 조건: `largest_red_area_ratio >= 0.00247`

NG 조건: `largest_red_area_ratio < 0.00247`

NG Reason: `NG_RED_CAP_MISSING`

## 7. 결과 해석

잘 동작한 부분:
- 정상은 0.0049~0.0069, 불량은 0.0000으로 차이가 매우 크다. 기준값 0.00247과도 여유가 크다.
- 병따개가 뚜껑 일부를 가린 `ok_03`에서도 윤곽선이 뚜껑을 정확히 잡았다(결과 이미지로 확인).
- 병의 위치가 Frame마다 달라도 색으로 찾기 때문에 영향을 받지 않았다.

문제가 있었던 부분:
- 처음의 넓은 빨강 범위에서는 피부와 콜라가 함께 검출되었다.
- `ok_03`은 비율이 다른 정상보다 높고(0.0069) 빨간 객체가 4개다. 뚜껑 근처 손가락 끝 일부와 손 조각이 함께 잡힌 것으로 보인다. 판정에는 영향이 없었다.

수정한 내용:
- 한 번에 한 가지씩 바꿨다: ① 측정으로 원인 확인 → ② H 범위만 좁힘(10 → 4/5 비교) → ③ V 하한으로 콜라 제외 → ④ Morphology 추가.

## 8. 결론

이 검사에서 가장 중요했던 Feature: **H(색상) 범위로 만든 빨강 마스크의 가장 큰 객체 면적 비율**. 측정 Feature보다도 "어떤 색만 남기느냐"를 정하는 마스크 조건이 결과를 좌우했다.

이 Rule이 실패할 수 있는 조건:
- 조명이 바뀌어 뚜껑의 H나 V가 달라질 때(노란 조명, 어두운 환경)
- 손이나 배경에 비슷한 빨간색(H 0~4)의 물체가 있을 때 → 뚜껑이 없어도 OK로 판정될 수 있음
- 카메라 거리가 바뀌어 뚜껑이 매우 작게 보일 때 → 면적 비율이 기준값보다 작아질 수 있음
- 같은 영상의 Frame을 사용했기 때문에 촬영 조건이 거의 같다. 다른 병, 다른 촬영에서는 다시 확인해야 한다.
